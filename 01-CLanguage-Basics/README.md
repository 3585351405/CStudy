## 🔑 核心知识点

### 数据类型
```c
// 基本数据类型及其大小（字节）
char        // 1 字节，-128 ~ 127
short       // 2 字节，-32768 ~ 32767
int         // 4 字节，-2147483648 ~ 2147483647
long        // 4 字节（与 int 相同，取决于系统）
long long   // 8 字节
float       // 4 字节，单精度浮点
double      // 8 字节，双精度浮点
```

### 变量定义
```c
int age = 25;                      // 基本变量
const int MAX_SIZE = 100;          // 常量（const）
#define PI 3.14159                 // 宏常量（#define）

// 变量初始化
int arr[5] = {1, 2, 3, 4, 5};     // 数组初始化
char str[] = "hello";              // 字符串初始化
```

### 运算符分类

#### 算术运算符
```c
+ (加)  - (减)  * (乘)  / (除)  % (取模)
```

#### 逻辑运算符
```c
&& (与)  || (或)  ! (非)
```

#### 关系运算符
```c
== (等于)  != (不等于)  < (小于)  <= (小于等于)
> (大于)  >= (大于等于)
```

#### 赋值运算符
```c
=    +=    -=    *=    /=    %=    &=    |=    ^=
```

#### 位运算符
```c
& (与)  | (或)  ^ (异或)  ~ (非)  << (左移)  >> (右移)
```

### 控制流

#### 条件语句
```c
if (condition) {
	// 执行代码
} else if (other_condition) {
	// 执行代码
} else {
	// 执行代码
}

switch (value) {
	case 1:
		// 执行代码
		break;
	case 2:
		// 执行代码
		break;
	default:
		// 默认情况
}
```

#### 循环语句
```c
// for 循环
for (int i = 0; i < 10; i++) {
	// 循环体
}

// while 循环
while (condition) {
	// 循环体
}

// do-while 循环（先执行再判断）
do {
	// 循环体
} while (condition);
```

#### 三元运算符
```c
condition ? value_if_true : value_if_false
```

## 💡 重要概念

### 1. 常量 vs 变量
- **常量**：值不变，使用 `const` 或 `#define`
- **变量**：可以修改
- 常量提高代码的可维护性和安全性

### 2. 整数类型的选择
- `char` - 单个字符或小整数
- `short` - 范围有限的整数
- `int` - 通用整数类型（推荐）
- `long long` - 大整数

### 3. 浮点数精度
- `float` - 单精度，精度较低
- `double` - 双精度，精度较高（推荐）
- 浮点运算存在精度误差，要特别注意比较

### 4. 运算符优先级
记住常用的优先级顺序（高到低）：
1. () [] . ->（括号、数组、成员访问）
2. ! ~ + - * &（逻辑非、位非、正负号、指针）
3. * / %（乘除模）
4. + -（加减）
5. << >>（位移）
6. < <= > >=（比较）
7. == !=（等于）
8. &（位与）
9. ^（位异或）
10. |（位或）
11. &&（逻辑与）
12. ||（逻辑或）
13. ?:（三元）
14. =（赋值）

### 5. 循环结构选择
- `for` - 已知循环次数时使用
- `while` - 条件不确定时使用
- `do-while` - 至少执行一次时使用

## ⚠️ 常见错误

### 错误 1：整数溢出
```c
int x = 2147483647;
x = x + 1;  // ❌ 溢出！结果为 -2147483648
```
**解决方案**：选择合适的数据类型，如 `long long`

### 错误 2：浮点数比较
```c
double a = 0.1 + 0.2;
if (a == 0.3) {  // ❌ 可能不成立（精度问题）
	// ...
}
```
**解决方案**：使用误差范围比较
```c
if (fabs(a - 0.3) < 1e-9) {  // ✅
	// ...
}
```

### 错误 3：除数为零
```c
int x = 5 / 0;  // ❌ 运行时错误
```
**解决方案**：在除法前检查
```c
if (divisor != 0) {
	result = dividend / divisor;
}
```

### 错误 4：无限循环
```c
while (1) {  // ❌ 如果没有 break，永不停止
	// ...
}
```

### 错误 5：scanf 的地址符号
```c
int x;
scanf("%d", x);      // ❌ 错误，必须用 &
scanf("%d", &x);     // ✅ 正确
```
